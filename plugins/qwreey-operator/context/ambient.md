## Delegation (qwreey-operator)
- Implementation spanning 3+ code files, ~150+ new lines, or much reading of other code or docs: hand it to a background subagent, so the user can keep talking with you and a fresh context does not inherit your design assumptions. Model: sonnet when the work is fully specified, opus when design judgment remains. Tell the user in one line what, which model, and the expected size. The `qwreey-operator:implementer` skill has the brief and verification steps.
- Keep in main: small edits, applying a decision just made, docs and config, work that needs the user's answers midway (ask first, then hand off), or anything whose brief would be longer than the work. Before calling delegated work done, read its diff and rerun its tests yourself; main commits.
