# 코드 재사용 규약 참고 (사람용)

모델이 지킬 것은 `rules/code-reuse.md` 에 있고, 코드 파일을 열거나 쓸 때 훅이 그 본문을 넣는다. 다른 패키지나 저장소로 정의를 옮겨 적을 때의 표시, 영역 복사와 동기화, 사본을 비교하는 시험, 라이브러리와 직접 구현을 가르는 측정 단계는 모델이 부르는 `qwreey-conventions:code-reuse` 스킬에 있다. 지켜졌는지는 `reuse-check.py` 가 보고 알림에 고치는 법을 담는다(검사 항목은 [how-it-works.md](how-it-works.md) 의 사본 검사 절). 이 문서는 값의 종류를 가르는 표와 저장소 설정을 사람이 찾아보는 곳이다. 모델에게 실리지 않는다.

## 정책인가 불변식인가
값이 다른 프로젝트에서 달라질 법하면 정책(설정, 코드에는 `DEFAULT_*` 기본값)이고, 형식이나 바깥 사실이나 안전이 정하면 불변식(`const`)이다.

| 값 | 종류 | 둘 곳 |
|---|---|---|
| 건너뛸 폴더, 색인할 확장자, 크기 한도, 단계 사다리, 도구 이름 목록 | 정책, 다른 저장소에 대고 도는 코드 | 설정 키, 코드에는 `DEFAULT_*` |
| Roblox, Wally, pesde 폴더와 패키지 이름 | 정책, 생태계 | 설정, 또는 그 생태계의 팩(제안) |
| 게임이나 앱 저장소의 밸런스 수치, UI 크기, 색 | 저장소 자신의 설계 | `const` 나 저장소의 데이터 모듈. 설정 아님 |
| 스키마나 프로토콜 버전, 알려진 frontmatter 키, 문법 표 | 불변식(형식) | `const` |
| 도구 입력 키, 바깥 도구가 정한 OS 경로 | 불변식(바깥 사실) | `const`, 뻔하지 않으면 출처 한 줄 |
| 보안 허용 목록 | 불변식(안전) | `const`. 넓히는 것은 설정 편집이 아니라 코드 리뷰 |
| 캐시 상한, 정리 기한 | 내부 | `const` |
| 클라이언트와 서버(또는 한 게임의 두 스크립트)가 맞춰야 하는 값 | 공유 사실 | 둘 다 `require` 하는 모듈 하나. "X 와 같음" 주석으로는 모자람 |

접두어 `DEFAULT_` 는 덮어쓸 수 있다는 약속이다. 아무것도 덮어쓰지 않는 값은 그냥 `const` 다.

## 저장소 설정
저장소의 `.claude/conventions.json`, 키 `reuse`(모두 선택):

```json
{"reuse": {"mode": "on", "allow": [{"path": "src/legacy/**", "reason": "frozen"}],
           "vocab_ok": [["Edit", "Write", "MultiEdit"]], "min_shared": 3}}
```

- `mode`: `shadow`(기본. 같은 목록 중복 검사는 기록만 하고 보이지 않는다), `on`, `off`. 환경 변수 `REUSE_CHECK` 가 이긴다. `@copy-of` 검사는 `off` 가 아니면 돈다.
- `allow`: 묶음을 알리지 않을 글롭, 각각 이유와 함께.
- `vocab_ok`: 바깥 어휘로 아는 묶음. 이 문자열만으로 된 겹침은 알리지 않는다.
- `min_shared`: 겹친다고 볼 공유 문자열 수(기본 3).
- 훅은 `.claude/`, `*-ignoreme*`, 벤더 트리, 생성 파일, 시험, stories, galleries, examples, `refs/` 를 보지 않는다.

## 같은 목록 알림
`mode: on` 일 때 추가한 문자열 묶음이 다른 정의와 겹치면 알림이 고치는 법을 함께 준다: 가져올 수 있으면 그 정의를 참조하거나 둘 다 가져오는 모듈 하나로 옮기고, 가져올 수 없으면 `@copy-of` 로 표시하고 시험에서 비교하며, 프로젝트마다 다른 값이면 `DEFAULT_*` 기본값을 둔 설정으로, 겉만 닮았으면 다른 사실인 이유를 담은 `@dup-ok: <이유>` 를 위에 단다. 손댄 파일에 전부터 있던 중복은 턴 끝에 사용자에게 한 줄로 셀 뿐이고, 정리하려면 "기존 문제도 정리해줘" 라고 한다.
