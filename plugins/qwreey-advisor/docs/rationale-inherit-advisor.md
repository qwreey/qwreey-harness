# qwreey-advisor:inherit-advisor 설계 근거와 측정 (옛 이름 context)

SKILL.md 에서 옮겨 온 내용이다(지시가 아니라 근거). 원문은 `.claude/scopes/plugins/qwreey-advisor/audit/18` §11·§12.

## 근거 (.claude/scopes/plugins/qwreey-advisor/audit/18 §11·§12, advisor 호출 시점 재현, opus)
- 대화를 받은 쪽(이 스킬)은 advisor 가 잡은 "흐름에만 있던" 문제를 다시 잡았다. diff 를 받은 쪽(`qwreey-advisor:fresh-advisor`)은 0건이었다. 대신 diff 쪽은 실측 버그를 잡았다. **둘은 대체재가 아니다.**
- fork 에 아무 지시 없이 질문만 붙이면 메인처럼 1인칭으로 답하고, 메인이 방금 끝낸 설계를 다시 열지 않았다(§11.4).
- 후행 프롬프트로 "독립 검토자" 역할과 사각지대 범주를 주면(§12 의 V2) 1인칭이 사라지고(0/6) 방금 끝낸 설계를 반례로 다시 열었다. advisor 4건 완전 회수는 4/8 로, 다른 시스템 프롬프트(3/12)보다 높았다(방향만, 표본 작음). 역할만 주고 범주를 빼면 설계를 다시 열지 않았다. **범주 목록을 빼지 않는다.**
- 내장 advisor 도구는 평소에 쓰지 않는다. 가격 대비 효용이 diff 기반 리뷰보다 낮다. 사용자가 요청할 때만 쓴다(`.claude/scopes/plugins/qwreey-advisor/audit/18` §3.3). 이 스킬은 advisor 도구를 부르지 않는다.
- 시점표의 "큰 전환점" 행과 "요구 대조" 줄은 §12 의 V3 에서 나왔다. 요구 대조는 넓게 찾는 대신 4번 범주가 얕아질 수 있다(§12.4).

## 후행 프롬프트와 표지(훅 펼침)
- 메인은 짧은 표지(`[qwreey-advisor:inherit] ...`, `next:`, `options:`)만 보내고, 플러그인 PreToolUse 훅(`hooks/expand-inherit-prompt.py`)이 `updatedInput` 으로 `templates/fork-prompt.md` 원문으로 바꾼다. 메인이 원문을 매번 Read·출력하지 않게 하고, 한국어 원문이 어긋나지 않게 하려는 것이다.
- 실측(2026-11-11, sonnet `-p`): matcher `Agent` 로 fork 호출에 걸린다. `permissionDecision: "allow"` 와 함께 준 `updatedInput.prompt` 로 fork 가 바뀐 prompt 를 받았다. 메인 트랜스크립트의 tool_use 에는 모델이 쓴 원래 표지가 남고, fork 트랜스크립트에는 바뀐 prompt 가 들어간다. 공식 문서는 `permissionDecision` 없이 `updatedInput` 만 주면 auto 모드가 바뀐 호출을 거절할 수 있다고 한다.
- 표지 자체가 안전한 최소 지시(검토만, 작업·편집·커밋 금지)라 훅이 없거나 실패해도 fork 는 작업을 이어 하지 않는다.
- §12 의 V2 에 작업 금지 문구와 다음 단계 한 줄을 붙인 꼴이다. 한국어 원문은 실험으로 굳힌 것이라 번역하지 않는다.
- 실험(§12)에서는 작업 금지 문구가 앞 턴에 따로 있었고 도구 한도는 10회였다. 한 메시지로 합친 현재 꼴과 5회 한도는 그대로 재지 않았다.
- 범주 2 의 "주입 경로, 다른 사용자·세션"을 이름만 두는 이유: 지금 세션의 구체적인 의심(예: "X 가 Y 에 새는가")을 넣으면 그쪽만 보고 돌아온다(§11.2 의 주장 목록 효과와 같다).
- fork 는 메인과 같은 모델로만 돈다(모델 지정이 무시된다). 메인이 opus 면 opus 다.

## fork 비용 [실측 §12.5 + 추정]
- fork 의 첫 호출은 메인이 방금 보낸 요청의 접두를 캐시에서 읽는다. 30만 토큰 맥락에서 실측한 2단 fork 는 1회 $0.44~0.70 이었다(도구 3~7회, 출력 7~11k 토큰). V2 는 $0.51~0.60.
- 구성은 캐시 읽기 약 절반(호출마다 맥락 전체를 다시 읽는다), 출력 약 1/3 이다. 그래서 도구 호출 수가 비용을 정한다. 도구 없이 한 번에 답하게 하면 약 $0.25 다(추정).
- 메인이 TTL 넘게 쉬어 캐시가 식었으면 맥락 전체를 다시 쓴다. 30만 토큰이면 opus 약 $1.5(5m)~2.4(1h) 가 더 든다. 메인이 방금 응답한 직후에 부른다.
- 결과 보고(약 2~3k 토큰)는 메인 맥락에 들어가 이후 매 턴 읽힌다.

- 영어판 채택: 핵심 효과(끝난 설계 다시 열기, 1인칭 없음, 놓친 것 찾기)가 같았고 출력 토큰은 약 절반이었다.
- 비용 수치: fork 1회 약 $0.5-0.6(30만 토큰, opus). 위 "fork 비용" 절 참고.
