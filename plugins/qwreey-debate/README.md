# qwreey-debate

이 플러그인을 켜면 Claude 가 혼자 정하지 못하는 선택이나 첫 생각만으로 정해 버릴 뻔한 선택을 토론에 붙인다. 서브에이전트 둘이 같은 근거를 받고 맞선 입장(예: 가장 작게 바꾸기 대 넓게 덮기, 지금 안 유지 대 교체)에서 의견서를 쓴다. 토론자는 받은 자료만 보지 않고 코드와 기록을 더 읽거나 웹과 공식 문서를 찾아 Claude 가 몰랐던 사실을 끌고 온다. 먼저 지금 안의 약한 근거를 짚고, 대안을 내고, 나온 대안마다 장단점을 붙인다. Claude 가 둘을 종합해 "무엇이 갈렸고 어느 쪽을 왜 골랐는지" 표와 바로 적용할 문구 초안을 보여 주고, 결정은 사용자가 한다. "토론 붙여봐", "토론시켜 봐", "찬반 붙여" 처럼 말하면 되고, Claude 가 이름·규약·매 세션 실리는 문구를 정하기 전에 스스로 꺼내기도 한다.

## 무엇이 달라지나
- 토론을 띄우기 전에 질문, 두 입장, 모델, 라운드 수, 대략의 비용을 한 줄로 알린다.
- 기본은 opus 둘, 1라운드다. 한쪽 의견서에서 확인할 수 있는 사실로 갈리거나 둘이 각자 더 나은 답의 절반씩을 쥐었을 때만 반박 라운드를 더한다. 재 보면 가려지는 갈림은 토론을 더 하지 않고 잰다.
- 종합은 함께 확인한 사실, 둘 다 받아들인 것, 갈림 표, 대안별 장단점, 적용할 문구, 받지 않은 것과 이유, 사용자에게 물을 것으로 나온다. 새 이름·필드·규약은 근거가 한쪽으로 기울어도 사용자에게 묻는다.
- 의견서는 사용자 언어로 쓰고, 제안 문구는 실제로 쓰일 언어로 쓴다(스킬 문구면 영어).
- 사용자가 답한 뒤 종합만 `.claude/audit/NN-<주제>/synthesis.md` 로 남긴다. 의견서 원문은 옆의 `raw/` 에 두고 커밋하지 않는다(git 무시 설정이 없으면 추가한다).
- 다른 회사 모델을 쓸 수 있게 해 두었다면(qwreey-delegate, MCP, CLI 등) 이름이나 생태계 관례 문제, 또는 Claude 의 틀 자체가 의심될 때 제3 목소리로 붙이는 것을 고려한다. 기본은 아니다. Claude 모델들(sonnet, opus)은 뿌리가 같아 같은 데서 함께 놓칠 수 있어서, 쓸 수 있는데 붙이지 않으면 고지 줄에 그렇게 적는다.

## 쓰지 않는 때
- grep, 측정, 시험 실행으로 답이 나오는 사실 문제. 재서 근거에 넣는다.
- 작은 선택, 이미 사용자가 정한 것, 결함 찾기나 전체 감사.

## 비용
- 늘 드는 것: 스킬 설명 한 줄(영문 약 650자). 훅 없음.
- 실행(어림값, 아직 원장으로 재지 않음): opus 둘 1라운드 약 $1, 2라운드 약 $2~3. 웹 조사를 하면 더 든다. 제3 목소리는 그 도구의 구독 한도에서 나간다.

## 요구 사항
- Claude Code 서브에이전트가 도는 곳이면 어디서나(구독만으로 충분). Linux·macOS·Windows.
- 다른 모델 계열은 선택. 쓰려면 그 도구(예: qwreey-delegate 플러그인과 agy·codex 구독)를 따로 갖춰야 한다.

## 끄기
- `claude plugin disable qwreey-debate@claude-doctor-market` (제거는 `uninstall`). 훅이 없어 끄면 바로 멈춘다.

## 설치
```bash
claude plugin marketplace add <claude-doctor 폴더>   # 마켓을 처음 쓸 때 한 번
claude plugin install qwreey-debate@claude-doctor-market
```
