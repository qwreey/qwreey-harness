# qwreey-desk

채팅에는 훅 알림, diff, 서브에이전트 시작과 끝, 접힌 보고가 함께 흘러가서 "정해 주세요" 하는 질문이 금방 위로 밀려납니다. 이 플러그인은 그런 질문과 지금 도는 일, 다음 순서를 채팅 밖 한곳(책상)에 모아 둡니다. 휴대폰 폭의 터미널에서도 읽히게 만들었습니다.

## 무엇이 달라지나
- 입력창 위에 한두 줄이 늘 보입니다: `결정 3 (막힘 1) · 실행 2 · 지금: <단계>`. 내용이 없으면 숨습니다.
- `/desk` 로 책상을 엽니다(`/desk 닫기` 로 닫음). 탭은 셋입니다.
  - 답을 기다림: Claude 가 올린 결정. 한 줄 목록에서 골라 들어가면 맥락, 선택지와 추천·이유, 코멘트 기록이 보입니다. 급한 정도(막힘, 곧, 나중) 순으로 놓이고, 끝난 결정은 구분선 아래에 최근 것부터 흐리게 남습니다.
  - 작업: 계획을 세로 타임라인으로. 지금 단계가 위에 오고, 끝난 단계는 위로 올려 봅니다.
  - 기록: 한 일이 시간 순서대로 쌓이는 피드(아래가 최신). Claude 가 남긴 요약은 또렷하게, 결정·서브에이전트·끝난 단계는 흐리게 한 줄씩 들어가고, 줄임표 없이 끝까지 보입니다. 날이 바뀌면 날짜 구분선이, 마지막으로 이 탭을 연 뒤 새로 생긴 기록 위에는 `여기부터 새로` 선이 놓입니다. 최근 500개를 남깁니다.
- 답하는 법: 선택지를 누르고 코멘트를 쓴 뒤 `보내기` 로 여러 결정을 한 번에 보냅니다. 코멘트만 보내면 결정은 열린 채로 남고 Claude 가 그 결정에 답글을 달거나 결정을 다듬습니다. 채팅에 `Q3: b`, `Q3 코멘트: …` 라고 써도 기록됩니다(예전 이름 `D3` 도 같은 결정).
- 권장과 다른 선택지를 고르면 결정 화면과 `보내기` 화면에 권장이 무엇이었는지 한 줄 보이고, 그 결정에 코멘트(또는 결정 번호를 적은 전체 메모)가 없으면 이유를 한 줄 남기라는 경고가 뜹니다. 막지는 않습니다.
- 서브에이전트와 백그라운드 명령은 시작과 끝이 자동으로 "지금" 에 들어갑니다(모델 토큰을 쓰지 않음).
- Claude 쪽에는 `desk` 도구가 생깁니다. 결정이 필요한 질문은 책상에 올리고 채팅에는 "Q5 올림" 한 줄만 남깁니다. 대화창에서는 이 도구 호출이 흐린 한 줄로 보이고, ctrl+o 로 원문을 봅니다.

## 저장
- 결정과 계획은 프로젝트의 git 저장소 안 파일로 남아 동료도 봅니다(coderag 기록 규약의 `.claude/plan/`).
  - 답을 기다리는 결정: `.claude/plan/decisions/Q<번호>-<제목 몇 단어>.md`. 질문, 맥락, 선택지와 추천, 코멘트가 들어 있습니다.
  - 답한 결정: 답을 적고 `.claude/archive/plan/decisions/` 로 옮깁니다(git 이 추적하던 파일이면 `git mv`).
  - 계획: `.claude/plan/now.md` 를 바뀔 때마다 새로 씁니다. 지난 계획은 git 기록에 있습니다.
- 책상은 커밋하지 않습니다. 쓴 파일은 `git status` 에 보이고 다음 커밋에 함께 들어갑니다.
- 파일이 진실입니다. 다른 세션이나 `git pull` 이 파일을 바꾸면 책상을 열 때, 세션을 시작할 때, Claude 가 책상을 쓸 때 다시 읽습니다. 사람이 파일을 조금 고쳐도 됩니다(모르는 절은 그대로 둡니다).
- 결정 번호는 `Q` 입니다. 예전 책상의 `D1`… 은 같은 번호의 `Q1`… 로 옮겨졌고, 그 전 커밋 메시지의 `D12 a` 는 `Q12` 를 가리킵니다(`base/decisions/D-12` 와 다름).
- 패널 상태(기록 탭, 읽음 표시, 보내기 전 선택과 코멘트, 단계 시각)는 프로젝트(작업 폴더)마다 Claude Code 의 플러그인 저장소에 남습니다. 같은 프로젝트에서 세션 둘이 동시에 쓰면 이 상태는 나중에 저장한 쪽이 이깁니다. worktree 는 폴더가 달라 책상도 따로이고, 파일도 그 worktree 의 브랜치에 생깁니다.
- git 저장소가 아니거나 파일을 쓸 수 없는 폴더에서는 전처럼 플러그인 저장소에만 두고, 입력창 위 줄에 한 번 알립니다.

## 비용
- 늘 드는 것: `desk` 도구 설명 한 단락(영문 약 1.2k자).
- 결정을 올릴 때마다 Claude 가 맥락을 적는 출력 토큰. 채팅에 같은 설명을 다시 쓰지 않으니 대신 줄어드는 몫도 있습니다.

## 알려진 한계
- 패널은 Claude Code mod API(2.1.316)에 기댑니다. 입력칸에 Enter 를 누르면 Claude Code 가 칸을 비우는데, 코멘트는 올라간 뒤입니다.
- 일부 기호(`●`, `▸`, `│`)는 터미널·글꼴에 따라 두 칸으로 그려져 줄이 어긋날 수 있습니다(Windows xterm.js 에서 봄).
- 휴대폰 앱(mobile 표면)에는 입력칸이 없어 코멘트는 채팅으로 씁니다.
