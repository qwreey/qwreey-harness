# context (컨텍스트) — Claude 의 책상

> 한 줄: Claude 가 **지금 한 번에 보고 있는 모든 글**. 책상 크기는 정해져 있고, 차면 흐려지고 비싸진다.

## 쉽게 말하면
- Claude 는 대화를 "기억" 하는 게 아니라, 매번 **책상 위에 펼친 종이 전부**를 다시 읽고 답한다.
- 책상 위에 올라가는 것:
  - 시작하자마자: Claude Code 기본 지시문, CLAUDE.md, auto memory, 스킬 이름·설명, MCP 도구 이름
  - 일하면서: 내가 친 말, Claude 의 답, Claude 가 연 파일 내용, 명령 실행 결과, 훅이 넣은 알림
- 이 종이 양을 재는 단위가 **토큰**이다. 글자 몇 개가 토큰 하나쯤 된다(언어마다 비율이 다르다).
- 책상(컨텍스트 창) 크기는 모델마다 정해져 있다. 일부 모델은 100만 토큰까지 쓸 수 있다.

## 차면 왜 나빠지나
1. **흐려진다.** 종이가 많을수록 중요한 지시가 묻힌다. 공식 문서도 "긴 CLAUDE.md 는 컨텍스트를 더 쓰고 지시를 덜 지키게 한다" 고 쓴다.
2. **비싸진다.** Claude Code 는 질문할 때마다 대화 전체를 다시 보낸다. 하루 종일 연 세션에서는 한 줄 질문도 대화 전체만큼 사용량을 쓴다.
3. **요약된다.** 한계에 가까워지면 자동으로 compact(요약)된다. 요약하면서 세부가 빠질 수 있다. → `compact.md`
4. **엉뚱한 것을 끌고 온다.** 아까 하던 다른 일의 흔적이 다음 일에 섞인다.

## 직접 확인하기
- `/context` 를 입력하면 지금 무엇이 얼마나 자리를 차지하는지 종류별로 보인다(CLAUDE.md, memory, 스킬, 대화 등).
- `/usage` 는 사용량과 무엇이 사용량을 많이 썼는지 보여 준다.
- 상태줄(status line)에 컨텍스트 사용량을 늘 띄워 둘 수도 있다(설정 변경이므로 동의 필요).

## 이렇게 하면 좋다
- **일이 바뀌면 `/clear`.** 이전 대화는 저장돼 있어서 나중에 `/resume` 으로 돌아갈 수 있다. → `session.md`
- 큰 파일·긴 로그 조사는 subagent 에게 맡기면 내 책상에는 요약만 온다. → `subagent.md`
- 항상 읽히는 것(CLAUDE.md, MEMORY.md, 스킬 설명)은 짧게 유지한다. → `memory.md`
- "이 폴더 전부 읽어 봐" 보다 "이 파일의 이 부분" 처럼 좁혀서 시킨다.

## 흔한 오해
- "창이 크면 다 기억하니까 괜찮다" → 커도 묻히는 문제와 비용 문제는 그대로다.
- "Claude 가 어제 대화를 기억한다" → 기억하는 게 아니라 파일(CLAUDE.md, memory)에 적힌 걸 다시 읽는 것이다.

## 역할별 예
- 아티스트: 에셋 목록 수백 줄을 붙여 넣고 계속 대화하면 뒤로 갈수록 엉뚱한 답이 늘 수 있다. 필요한 부분만 주고, 주제가 바뀌면 `/clear`.
- Luau 개발자: 큰 모듈 여러 개를 연달아 읽히면 금방 찬다. "어디서 쓰이는지 찾아 줘" 는 subagent 로.
