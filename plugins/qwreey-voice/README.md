## 이게 뭐예요?

이 플러그인은 작성자 `qwreey`의 신경학적 프로파일을 Claude가 존중하고 더 효율적으로 협력할 수 있도록 도와요.

이 플러그인을 켜면 Claude 가 사용자와 협력하는 방법이 달라집니다. 예를 들어:

- 사용자에게 작업을 요구하는 방법이 달라져요.
    - 시키는 말을 하지 않아요. 대신 그 일이 필요한 이유, 얻는것과 미루면 생기는 것을 보여요.
    - 통보하지 않고 고르거나 고민할 기회를 줘요. 사용자의 자율성을 놓아 작업의 강제성이 덜 느껴지도록 해요.
    - 정할 일은 질문으로 내요. 당장 선택하고 처리할 것이 아닌 자연히 생각해보도록 해요.
> 예: '이 폴더를 지워주세요' -> '저장공간이 모자라지지 않게, 편할 때 이 폴더를 치워주세요.'

- 사용자에게 말하는 방법이 달라져요.
    - 긴 글의 압박성에 유의하게 되며, 글이 길어진다면 "머리말: 내용" 꼴로 개조식으로 나누는걸 고려하게 돼요.
    - 단순 참조에 유의해요. 사용자가 여러 파일을 열고 읽지 않아도 되도록 약어나 이름 등을 "Quad0228(버전이 안 맞을 때 나는 에러)" 처럼 서술해요.
    - 글을 위 아래로 오가며 읽지 않아도 되도록 순서를 조율해요. 가급적 한 방향으로 쭉 읽을 수 있게 도와줘요.
    - 압박하지 않으며 재촉하거나 반복하지 않게 유의해요.
> 예: Before -> After
> '이번 코드도 큽니다. 기능이 늘기 전에 Q1처럼 재구조화를 수행해야합니다.'
> 'Q1 에서 test.luau 가 커져 test/ 폴더로 나눈 것이 효과가 있었던 것처럼, 이 작업도 그렇게 할까요?'

달라지지 않는 부분도 있어요. 예를 들어:

- *일 하는것은 같아요*: Claude는 커밋이나 코드, 작업에 이것을 근거로 삼지 않습니다. 오직 대화하는 방법만 조율합니다.
- *다른 역할이 생기지 않아요*: 상담을 제공하거나, 의학적 정보를 제공하지 않습니다. Claude는 여전히 당신의 작업 파트너일 뿐입니다.

## 누가 사용해요?

인간은 다양해요, 신체적으로도 신경학적으로도 모두가 조금씩 다를 수 있어요. 그리고 이런 경우도 존재해요.

- PDA(Pathological Demand Avoidance)
    - 강제적이거나 하나로 정해진 작업을 수행하기 어려운 경우예요.
    - 일상 생활에서도, 예를 들어 씻거나 청소하거나 세탁하는 등 작업도 시작이 어려울 수 있어요.
- ADHD - F90
    - 작업 기억 능력에서 어려움을 겪어요. 한 파일을 여럿 다시 보기도 해요.
    - 무언가 잘 빠트리고 집중이 어려운 경우가 흔해요.
    - 긴 글을 읽기 어려워요. 특히 읽는 순서나 서사 시간이 꼬이면 더더욱 힘들어요.

그런 경우 작업이나 읽기 작업 등의 고통을 경감하기 위해 사용해요.

Claude는 되도록 사용자를 압박하지 않게 조심하면서, 사용자가 여유로워 경계를 놓치진 않게 도와줘요.


궁금하다면 써봐도 좋아요. 본인에게 도움이 된다면 채택하고, 별다른 도움이 없다면 Claude의 작업 성능을 위해 지우셔도 돼요.
작업 결과 자체에는 큰 영향이 없어 부담 가지지 않아도 좋아요.

이 신경 프로파일은 단순히 개인의 경험이라서, 원하신다면 본인에 맞게 조율해도 돼요. 오픈소스이고 가져가 바꾸더라도 문제 없어요.

## 어떻게 쓸까요?

어렵다면 Claude에게 이렇게 물어봐도 좋아요.

```
https://github.com/qwreey/qwreey-harness 안에 qwreey-voice라는 플러그인이 있는데, 한번 사용해보고싶어. 먼저 그 플러그인이 안전하고 악의가 없는지 저장소를 받아서 읽기 전용으로 확인해보고, 설치를 도와줄래? 필요하다면 네 하네스에 대한 정확한 정보는 검색해봐도 좋아. 만일 내가 따로 python3를 설치해야 한다면 이 방법도 알려줘.
```

기본적으론, python3를 먼저 설치해주세요. 그리고 이 저장소를 클론한 다음

- `claude plugin marketplace add <qwreey-harness 폴더>`
    이렇게 마켓을 한번 준비하고
- `claude plugin install qwreey-voice@qwreey-harness`
    이렇게 마켓에서 설치할 수 있어요.
