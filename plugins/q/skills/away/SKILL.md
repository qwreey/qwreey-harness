# away

아래는 `/q:away` 를 실행한 결과다(출력이 이미 있으면 다시 실행하지 않는다. 실행 지시만 있으면 그 명령을 한 번 실행한다).

!`python3 "${CLAUDE_CONFIG_DIR:-$HOME/.claude}/lib/subagent_ledger.py" away ${CLAUDE_SESSION_ID} $ARGUMENTS`

## 쉬운 설명 (사용자에게 물으면 이대로)
자리를 비운 동안 "한도를 얼마나 쓰게 둘지" 정해 두는 기능이다.
- 정한 만큼 쓰면 1단계: 서브에이전트를 한 번에 하나씩만 돌린다(느려지지만 계속 간다).
- 정한 양의 두 배를 쓰면 2단계: 새 서브에이전트를 더 띄우지 않고, 지금까지 한 일을 파일에 적은 뒤 사용자가 올 때까지 기다린다.
- 돌아와서 `/q:back` 하면 얼마 썼는지, 1·2단계에 언제 닿았는지 요약한다.

예시
1. `/q:away 30%` : 지금부터 구독 한도(5시간·주간 중 먼저 닿는 쪽)를 30% 더 쓰면 1단계, 60% 면 2단계.
2. `/q:away 20%w` : 주간 한도만 보고 20%. 5시간 한도가 없는 요금제는 이 형태가 편하다(`30%5h` 는 5시간 창).
3. `/q:away $5` : 달러로 5(API 목록가 환산). API·종량제용. `6a` 는 서브에이전트 6개.

## 할 일
1. 위 결과를 사용자에게 그대로 한두 줄로 전한다. 오류가 나왔으면 형식(`/q:away [예산] [슬롯]`)을 알려 준다.
2. 결과에 표지가 있으면:
   - `[plan-unknown]` / `[no-limits]`: 한도 % 를 읽지 못해 USD 로 켰다. 사용자에게 한 번만 요금제를 묻는다(구독이면 `/q:away 30%`, 종량제면 USD). 구독인데 값이 없다면 상태줄(statusline)이 설정돼 있는지 확인하라고 안내한다. 매번 묻지 않게 `~/.claude/harness.env` 에 `HARNESS_AWAY_PLAN=pct`(또는 `usd`) 를 넣으라고 제안만 한다(대신 쓰지 않는다).
   - `[window-missing]`: 요금제에 없는 창이라 있는 창으로 켰다고 전한다.
3. 켜졌다면 이후 동작:
   - 서브에이전트를 띄우기 전에 남은 일의 규모를 보고, 작은 패스(찾기 → 리뷰 → 고치기 → 리뷰)를 순서대로 돈다.
   - `queue: …` 거절은 실패가 아니다. 실행 중인 에이전트의 완료 알림을 기다렸다가 다음 것을 띄운다. 같은 호출을 바로 다시 하지 않는다.
   - 예산을 넘겼다는 알림(1단계)이 오면 남은 일마다 "sonnet 으로 되는가, 더 작은 패스로 나눌 수 있는가"를 따져 다음 보고에 적는다.
   - `halt: …` 거절(2단계)이 오면 새 서브에이전트·Workflow 를 더 부르지 않는다. 진척 파일(없으면 세션 메모)에 한 일·진행 중인 것·다음 할 일·사용자 결정이 필요한 것을 적고 사용자를 기다린다. 세션은 멈추지 않으므로 하던 작은 일만 마무리한다.
   - 사용자가 돌아와 `/q:back` 하면 요약이 나온다.

## 인자
- 예산: `30%` 한도 %p(가장 빡빡한 창 기준), `30%w` 주간만, `30%5h` 5시간만, `$5`·`5` USD(메인 + 서브에이전트, `/q:away` 이후), `6a` 서브에이전트 6개.
  생략하면 한도 값을 받고 있을 때 `HARNESS_AWAY_BUDGET_PCT`(30%), 아니면 `HARNESS_AWAY_BUDGET_USD`(20).
- 슬롯: 동시에 돌 서브에이전트 수. 생략하면 `HARNESS_AWAY_SLOTS`(기본 2). 예산을 넘기면 `HARNESS_AWAY_OVER_SLOTS`(기본 1).
- `status` 지금 상태, `off` 끄기(= `/q:back`), `reset` 슬롯 카운터 비우기(카운트가 어긋났을 때).
- 한도 %는 상태줄 입력의 값이다. 상태줄이 10분 넘게 갱신되지 않으면 USD 가드로 보강한다.
- 설계와 문턱값: claude-doctor `audit/21-cost-disclosure.md`.
