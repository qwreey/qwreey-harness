# 흔한 실수와 대처 — 처음 쓰는 사람을 위해

> 한 줄: 대부분의 문제는 Claude 가 아니라 **맥락이 섞이거나, 요청이 모호하거나, 확인 없이 넘어가서** 생긴다.

| # | 흔한 실수 | 무슨 일이 생기나 | 대처 |
|---|---|---|---|
| 1 | 하루 종일 한 대화에서 이것저것 | 앞 일의 흔적이 섞이고, 느려지고, 비싸진다 | 일이 바뀌면 `/rename` → `/clear` |
| 2 | "고쳐 줘", "알아서 잘" | 엉뚱한 곳을 크게 고친다 | **무엇을, 어디서, 어떻게 되면 끝**인지 한 줄씩 |
| 3 | 허락 창을 읽지 않고 "예" | 원치 않는 파일이 바뀐다 | "무엇을, 어디에" 만이라도 읽는다. 모르면 "이게 뭐야?" 라고 묻는다 |
| 4 | 비밀번호·API 키·개인정보 붙여 넣기 | 대화 기록 파일에 그대로 남는다 | 절대 붙여 넣지 않는다. 필요하면 담당자에게 |
| 5 | 바탕화면·다운로드 폴더에서 바로 시작 | 상관없는 파일까지 작업 범위가 된다 | **작업 전용 폴더**에서 Claude 를 연다 |
| 6 | 백업 없이 큰 변경 | 되돌릴 수 없다 | 개발자는 git 커밋 먼저, 그 외는 폴더 복사본. `/rewind` 도 있지만 만능은 아니다 |
| 7 | 답을 그대로 믿기 | 그럴듯한 틀린 답 | "어떻게 확인했어?" "직접 실행해서 보여 줘" |
| 8 | 모든 걸 "기억해" | 메모가 커져 오히려 흐려진다 | 반복되는 것만. 가끔 `/memory` 로 정리 |
| 9 | 인터넷에서 본 플러그인·MCP 아무거나 설치 | 내 권한으로 남의 프로그램이 돈다 | 회사 마켓 것만. 그 외는 담당자에게 |
| 10 | 같은 파일·같은 Studio 를 두 세션이 동시에 | 서로 덮어쓴다 | 한 대상에는 한 세션 |
| 11 | subagent 를 "많이 써" | 사용량 급증 | 개수와 목적을 정해서. 먼저 물어보게 |
| 12 | 막혔을 때 "우회해서라도 해" | 보안 장치를 피해 가려다 사고 | 왜 막혔는지 묻고, 필요하면 담당자에게 |
| 13 | 모른다고 말하지 않기 | 전문 용어 섞인 답을 못 알아듣고 지나감 | "나는 프로그래머가 아니니 쉽게 설명해 줘" 라고 처음에 말한다 |
| 14 | 오류 메시지를 요약해서 전달 | 핵심 단서가 빠진다 | 오류 화면을 **그대로** 붙여 넣는다(비밀이 없을 때) |

## 좋은 요청의 틀
```
목표: (무엇을 하고 싶은지 한 줄)
대상: (파일·폴더·Studio 플레이스 이름)
조건: (건드리면 안 되는 것, 지켜야 할 것)
끝: (어떻게 되면 다 된 건지)
먼저 계획을 보여 주고, 내가 좋다고 하면 시작해.
```

## 비프로그래머에게 특히
- 처음에 "나는 아티스트고 코드는 모른다" 고 말해 두면 설명 수준이 맞춰진다.
- 결과를 눈으로 확인할 수 있는 형태(스크린샷, 표, 전/후 목록)로 달라고 한다.
- 이상하면 멈추게 한다: `Esc` 로 진행 중인 일을 멈출 수 있다.

## Luau 개발자에게 특히
- Roblox 전용 API 를 일반 Luau 로 착각하는 실수가 잦다. luau-kb 스킬을 쓰게 한다. → `roblox.md`
- Studio 상태를 바꾸는 MCP 도구는 동료가 같은 플레이스를 쓰는지 확인 후.

## 이해 확인 질문 (설명 뒤 하나만 골라 묻는다)
- '고쳐 줘' 대신 어떤 네 가지를 말하면 좋나요? (목표, 대상, 조건, 끝)
- 진행 중인 일을 멈추는 키는? (답: `Esc`)
