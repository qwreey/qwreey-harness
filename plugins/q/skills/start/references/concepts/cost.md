# 비용 — 무엇이 비싼가

> 한 줄: 비용은 대부분 **"매번 다시 읽는 양"** 에서 나온다. 긴 대화, 많은 subagent, 높은 effort, 비싼 모델이 크다.

## 기본 원리
- Claude Code 는 메시지를 보낼 때마다 **대화 전체**를 다시 보낸다. 도구를 한 번 쓸 때마다 또 보낸다.
- 반복되는 앞부분은 캐시(prompt caching)로 싸게 읽지만, 공짜는 아니다.
- 그래서 같은 질문도 **긴 대화 끝에서 하면 비싸고, 새 세션에서 하면 싸다.**

## 비싼 것 순위 (대략)
| 무엇 | 왜 | 줄이는 법 |
|---|---|---|
| 하루 종일 연 긴 세션 | 매 요청이 대화 전체를 끌고 간다 | 일이 바뀌면 `/clear` |
| subagent 여러 개, 에이전트 팀 | 각자 따로 요청을 보낸다. 에이전트 팀은 plan mode 에서 일반 세션의 약 7배(공식) | 꼭 필요할 때만, 개수를 정해서 |
| 쉬었다 와서 첫 메시지 | 캐시가 식어 전체를 다시 처리 | 긴 휴식 뒤 새 일이면 새 세션 |
| compact | 긴 대화를 한 번 다 읽어 요약 | 이어 갈 필요 없으면 `/clear`(비용 없음) |
| 비싼 모델(Opus 등) | 토큰당 값이 높다 | 일상 작업은 Sonnet 으로 충분한 경우가 많다(공식 권고) |
| 높은 effort | 생각한 양도 토큰 | 어려운 질문에만 `ultrathink` |
| 항상 읽히는 것 | CLAUDE.md, MEMORY.md, 스킬 설명, MCP 도구 이름 | 짧게, 안 쓰는 스킬·MCP 끄기 |
| 큰 파일·로그 통째로 읽기 | 책상을 채운다 | 필요한 부분만, 또는 subagent 에게 |
| 주기 작업(`/loop`, 예약 작업) | 대기 중에도 대화 전체를 보낸다 | 꼭 필요할 때만, 끝나면 끈다 |

## 확인하는 법
- `/usage` : 이번 세션 비용, 요금제 한도, **무엇이 사용량을 많이 썼는지**(스킬·subagent·플러그인·MCP 별 비율). 10% 넘게 쓰는 습관이 있으면 고칠 점을 추천해 준다.
- `/context` : 지금 책상 위 구성.
- 입력창 옆 스피너 옆 숫자: 이번 턴의 토큰 수.
- `/insights` : 최근 세션들을 분석한 보고서(어디서 막히는지, 써 볼 기능).

## 싸게 쓰는 습관 5가지
1. 한 일 = 한 세션. 끝나면 `/rename` → `/clear`.
2. 요청은 구체적으로: 대상 파일, 원하는 결과, 다 됐다는 기준. 헤매는 시간이 곧 비용이다.
3. 조사는 subagent 에게, 결과는 짧게 받기.
4. 모델·effort 는 기본값으로 두고 어려울 때만 올리기.
5. 안 쓰는 플러그인·MCP 서버 끄기(`/plugin`, `/mcp`).

## 흔한 오해
- "짧게 물으면 싸다" → 긴 대화 끝이면 짧은 질문도 비싸다.
- "subagent 를 쓰면 싸다" → 내 책상은 깨끗해지지만, 전체 사용량은 보통 는다.

## 이해 확인 질문 (설명 뒤 하나만 골라 묻는다)
- 같은 질문이 새 세션에서 더 싼 이유는?
- subagent 를 쓰면 전체 사용량은 보통 어떻게 되나요?
