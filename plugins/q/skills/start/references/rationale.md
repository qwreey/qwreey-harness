# q:start 설계 근거

- 동의 원칙이 맨 앞에 있는 이유: 회사 보안 정책상 동의 없는 작업은 거부된다. 비프로그래머 동료에게 배포하는 용도라(사용자 메모리 "회사 배포 맥락"), 파일 쓰기·설정·설치·외부 전송을 항목별 동의로 묶었다.
- 한 단계마다 멈추는 이유: auto mode 에서도 사용자의 답을 추측해 진행하지 않게 하려는 것이다.
- 개념 설명을 10줄 안팎으로 제한하고 파일(`references/concepts/`)로 뺀 이유: SKILL.md 를 짧게 유지하고 필요한 개념만 읽게 하기 위해서다(audit/24 §4).
- 본문 지시문은 영어, 사용자에게 그대로 보이는 문구(질문, 표, 제안 틀, 안내)는 한국어로 둔다(audit/24 §4 언어 정책, 2026-11-11 사용자 승인).
