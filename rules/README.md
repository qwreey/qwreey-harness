# rules — 경로 조건부 공통 규약 (아직 비어 있음)

이 디렉터리에는 여러 Luau 저장소가 함께 쓸 `paths:` 조건부 규칙 파일(`luau-*.md`)이 들어갈 자리다. 다른 작업(사용자 레벨 `~/.claude/rules/` 정리)에서 채운다.

- 규칙 파일은 frontmatter 에 `paths: ["**/*.luau"]` 처럼 범위를 반드시 단다. `paths` 가 없으면 매 세션 항상 로드되어 비용이 그대로다.
- 규칙에는 **강제할 관례**만 둔다(예: 파일마다 `--!strict`, 콜백에는 `<<T>>` 나 파라미터 주석). 근거와 사실은 `skills/` 의 references 를 가리키고 다시 쓰지 않는다.
- 정책이 갈린 항목(`decisions/README.md` 의 미결 목록)은 결정이 나기 전에는 규칙으로 만들지 않는다.
