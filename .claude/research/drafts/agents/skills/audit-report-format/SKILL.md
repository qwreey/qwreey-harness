# 감사 보고 형식 (공통)

감사 에이전트 다섯이 이 형식 하나를 같이 쓴다. 에이전트 본문에 형식을 다시 적지 않는다.

## 최종 메시지 규칙

- **마지막 메시지 하나에 최종 목록을 전부 담는다.** "나중에 보내겠다"는 약속을 하지 않는다. 다 못 본 것은 `미완`으로 적는다.
- 맨 위에 `## 범위` 절을 둔다. 다음 넷을 적는다.
  - 본 것: 파일과 디렉터리, diff 범위, 기준 커밋(`git rev-parse HEAD`로 직접 확인한 값)
  - 안 본 것: 시간이나 도구 제약으로 건너뛴 곳
  - 쓴 도구와 버전: 예) `luau-analyze 0.734 (new solver)`, `luau-lsp 1.69.0 analyze --flag:LuauSolverV2=true`
  - 프로젝트 정본: 판단 기준으로 읽은 문서 경로
- 발견이 없으면 `발견 없음`이라고 쓰고, 범위 절로 무엇을 확인했는지 밝힌다. 그럴듯해 보이려고 사소한 지적을 지어내지 않는다. 이 감사의 가치는 발견 개수가 아니라 정확도다.

## 발견 하나의 형식

```
### [높음|중간|낮음] 한 줄 요약
- 관점: types | runtime | quality | perf | docs
- 위치: `경로:줄` (구현이 없어서 생긴 문제면 "누락 — <무엇이 없는지>")
- 무엇이 깨지는가: 구체적인 실패 시나리오. 어느 공개 API를 어떤 인자로 부르면 무엇이 나오는지까지 적는다. "누수 위험" 같은 추상 표현은 쓰지 않는다.
- 증거: 코드 인용(파일에서 그대로 옮긴 몇 줄), 실행한 명령과 출력, 정본 문서의 절
- 재현 스니펫: 돌릴 수 있는 최소 코드와 실행 명령. 돌려 봤으면 출력도 붙인다. 못 돌렸으면 "미실측"이라고 쓰고 이유를 적는다.
- 증거 등급: 실측(직접 돌려 확인) | 대조(정본·문서와 맞춰 봄) | 추론(코드를 읽고 추정)
- 확신도: 높음 | 중간 | 낮음 — 왜 그런지 한 줄
- 사용자 판단 필요: 예 | 아니오 — "예"이면 이유를 적는다(아래 기준)
- 제안: 고치는 방향 한 줄. 새 필드·인자·이름·메커니즘이면 앞에 "제안(새 개념):"을 붙인다.
```

- 심각도는 셋만 쓴다.
  - **높음**: 불변식이 깨진다. 크래시, 조용히 틀린 결과, 타입이 거짓을 약속함.
  - **중간**: 특정 조건에서 깨진다. 누수, 엣지 케이스, 검사가 빠져 있음.
  - **낮음**: 정리할 거리. 실제로 깨질 일은 드물다.
- **사용자 판단 필요 = 예** 인 경우
  - 설계 의도가 바뀐 것일 수 있다. 예를 들어 문서가 낡았는지 코드가 틀렸는지 판단이 안 선다. 이때는 판정하지 말고 둘 다 적는다.
  - 고치는 방법이 둘 이상인데 고를 근거가 정본에 없다.
  - 처방이 새 공개 이름, 필드, 메커니즘을 요구한다. 이때는 "증상 확정, 처방 미정"으로 적는다.
  - 취향이나 방향의 문제다.
  - 애매하면 임의로 판정하지 말고 "예"로 올린다. 메인 세션은 사용자에게 물을 수 있지만 너는 물을 수 없다.

## 증거 규칙

- **실측과 추론을 가른다.** Roblox 엔진, Studio, 네트워크처럼 네가 돌릴 수 없는 것은 `추론`이다. 공식 문서를 읽었으면 `대조`로 쓰고 URL을 붙인다.
- **"진단 0건"이나 "테스트 통과"를 근거로 삼지 않는다.** 그 검사가 이 실수를 잡을 수 있다는 음성 대조군을 먼저 보여야 한다(luau-verify).
- 판정은 출력 줄 수가 아니라 **exit code**로 한다.
- 코드는 파일에서 그대로 인용한다. 줄 번호는 인용 직전에 다시 확인한다.
- 이미 알려진 것은 새 발견이 아니다. 호출 프롬프트가 원장, `archive/`, "알려진 한계" 문서를 주면 먼저 grep으로 확인한다. 겹치면 `## 기보고 확인` 절에 "기보고: <번호/경로>" 한 줄로만 남긴다.
- 의심했지만 정본이나 코드와 대조해 건전하다고 판단한 것은 `## 건전성 확인` 절에 한 줄씩 적는다. 다음 감사가 같은 것을 다시 의심하지 않게 하기 위해서다.

## 절 순서

1. `## 범위`
2. `## 발견` (심각도 순)
3. `## 기보고 확인`
4. `## 건전성 확인`
5. `## 미완` (없으면 생략)
