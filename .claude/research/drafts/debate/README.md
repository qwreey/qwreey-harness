# 토론 스킬 초안

이 저장소에서 자주 돌린 P/Q 토론(audit 25, 26, 29, 31, 38, 41, 48, 49, 50)과 quad 토론(`naming-table-review-2026-10-16`, `naming-marker-helper-2026-11-06`, `qa-request/code-quality-review-round15.md`)에서 실제로 쓰인 꼴을 스킬로 정리했다. 다음 토론에서 써 보고 문제를 여기 쌓은 뒤 다듬는다.

| 파일 | 내용 |
|---|---|
| `SKILL.md` | 언제, 입장 고르기, 브리프, 라운드, 종합, 기록, 비용, 실패 꼴 (영어, 약 70줄) |
| `templates/brief.md` | 1라운드 브리프 틀과 2라운드 덧붙임 |
| `templates/synthesis.md` | audit 종합 스냅샷 틀(48·49·50 synthesis 의 꼴) |

## 옛 초안에서 바뀐 것
- 옛 초안(`delegate/skills/debate/`)은 codex·agy·Claude 세 계열, 2라운드 기본, 원장 꼴, `/debate` 사용자 호출 전용이었다. 실제로 이 저장소에서 결정을 낸 토론은 opus 둘 P/Q 1-2라운드였고, 48·49·50 은 1라운드로 충분했다. 그래서 기본을 Claude 둘 1라운드로 바꾸고, 다른 계열은 이름·생태계 관례나 틀 밖 시선이 필요할 때의 제3 목소리로 내렸다(실행 방법은 `qwreey-delegate:delegate` 에 맡김).
- `rebuttal.md` 는 브리프 끝의 2라운드 덧붙임 몇 줄로 접었다. 2라운드는 드물고, 같은 에이전트를 이어 쓰면 1라운드 브리프를 다시 넣을 필요가 없다.
- `ledger.md` 는 `synthesis.md` 로 바꿨다. 라운드·모델별 표와 사실 확인 표 대신, 실제 종합들이 쓴 꼴(함께 확인한 사실, 합의, 갈림 표와 고른 쪽, 문구 초안, 받지 않은 것, 사용자 문항)을 따랐다.
- 실측으로 가를 수 있는 갈림은 2라운드 대신 잰다(25 judge-run, 26 replay, 29 measure, 31 probes). 재도 갈리지 않으면 사용자가 밝힌 선호를 따른다(25 에서 0/10 대 0/10 비김).
- 실패 꼴은 실제 사례에서: codex·Gemini 가 `asState` 로 수렴했지만 메인 grep 이 반증(quad), 41 의 1라운드 측정이 엉뚱한 루트를 잼(2라운드에서 상대가 잡음), 48 의 경로에서 `src/` 빠짐, Gemini 가 기각된 안을 다시 냄(round15), 다수결 동률(6·6·6).
- 모델용 문서라 영어로 쓰고 날짜·audit 번호는 이 README 로 뺐다.

## 열린 질문 (사용자)
1. **누가 부르나.** 모델이 스스로 부를 수 있게(지금 초안, 띄우기 전 한 줄 고지) 할지, `/debate` 사용자 호출 전용으로 둘지. 추천: 모델 호출. "전역 문구는 토론을 거쳐 확정" 방침과 "검토는 모델 몫"에 맞는다. 대가는 description 한 줄의 상시 로드.
2. **의견서 언어.** 지금은 "그 저장소 기록 언어"(여기선 한국어, 지금까지와 같음). 모델 사이 글은 영어라는 규칙을 따르면 영어가 된다.
3. **의견서 원문 보관.** 49·50 처럼 종합만 남길지, 매번 `round1-*.md` 를 남길지. 초안은 "종합이 인용하면 남김".
4. **비용 수치.** 1라운드 약 $1 은 2라운드 약 $2(세션 기록)에서 어림한 것이다. 다음 토론에서 서브에이전트 원장으로 잰다.
5. **제3 목소리 기본값.** 이름 쟁점이면 codex 를 기본으로 붙일지, 지금처럼 그때그때 판단할지.

## 착륙 위치
