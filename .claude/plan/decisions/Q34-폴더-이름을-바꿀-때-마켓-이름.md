# Q34. 폴더 이름을 바꿀 때 마켓 이름 claude-doctor-market 도 바꿀까?

## 맥락

**마켓 이름이 쓰이는 곳**
- 플러그인 id 전부: `q@claude-doctor-market` 등. 사용자 `settings.json` 의 enabledPlugins·pluginConfigs, 플러그인 데이터 폴더 11개(`~/.claude/plugins/data/<플러그인>-claude-doctor-market`: 세션별 상태, 캐시, 언어 설정)
- 형제 저장소 8곳의 `.claude/settings.json`(quad, vitrine, table-sim, devplorer, rbvm, moonwave-luau, nekolog, mrow; 팩을 켜는 키, coderag adapt 가 씀). 이 저장소에서는 읽기 전용이라 각 저장소 세션 몫
- 동료가 `claude plugin marketplace add qwreey/qwreey-harness` 로 더하면 보이는 마켓 이름도 이것(marketplace.json 의 name)

**바꾸면**: 동료 설치 전이라 지금이 가장 싸다. 대신 데이터 폴더 이동, 설정 키 바꾸는 마이그레이션, 형제 저장소 8곳에서 `coderag adapt` 다시 돌리기가 붙는다
**안 바꾸면**: 저장소는 qwreey-harness 인데 마켓은 claude-doctor-market 이라 이름이 어긋남(동작은 같음)

## 선택지

- a) 같이 바꿈 (qwreey-harness)
  이름이 하나로 맞고, 동료가 설치하기 전이라 나중보다 싸다. 형제 저장소 8곳은 각자 세션에서 adapt
- b) 마켓 이름은 유지
  폴더만 바꾸면 끝. 이름 어긋남만 남음

**권장 a) 같이 바꿈 (qwreey-harness)**
공개 저장소 이름과 사용자가 보는 마켓 이름이 다르면 README·설치 안내가 계속 헷갈림. 동료 설치 전인 지금 한 번에 바꾸면 이후 마이그레이션이 필요 없음. 형제 저장소 키는 coderag adapt 한 번이면 됨
