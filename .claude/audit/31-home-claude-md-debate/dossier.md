## 사용자 원문 취지 (2026-11-11)
- home CLAUDE.md 는 상황이 어떻게 되든 도움이 되는 쪽이어야 한다.
  - 형제 저장소 지도처럼 노트북이나 다른 기계에서 맞지 않는 것은 고쳐야 한다.
- "다른 저장소를 다룰 때" 는 제목 그대로 "다른 저장소를 다룰 때에는 ... 스킬 참조" 처럼, 필요할 때 볼 수 있는 경로로 두는 것이 좋다.
- 훅 메시지 규약은 이 환경에서 늘 깔려 있어야 하고(ambient), 상시로 켜져 있어야 한다.
- 스킬 중에 상시로 켤 수 있는 것이 있는지, 그런 식으로 정리할 수 있는지 묻는다.
- "다른 저장소" 는 훅으로 처리할 수 있는지 묻는다.
  - 바깥에 접근하려 하면 먼저 block 하고, 스킬을 확인하게 한 뒤, 로드됐으면 넘어간다.
  - compact 뒤 다시 로드되는 기준도 봐야 한다.
  - compact 는 생각보다 자주 일어나니, 이런 것이 상시 로드되면 안 된다.
- 앞선 결정:
  - 모델 사이의 텍스트는 영어다.
  - 전역 문구는 토론을 거쳐 정한다.
  - 사용자 선택(이름, 문구)은 제안만 한다.
  - 검토 기능은 모델이 스스로 부르는 도구로 둔다.

## 확인된 사실
### .claude/audit/30 실험
- 스킬 `paths`
  - description 만 거른다. 본문은 주입하지 않는다.
  - cwd 상대 glob 만 맞는다. 그래서 형제 저장소에는 쓸 수 없다.
- 게이트
  - PreToolUse 에서 deny 하면, 모델이 스킬을 호출하고, 재시도가 통과한다. 이 흐름이 성립한다.
  - 로드 감지는 두 가지다: PostToolUse(Skill) 의 `tool_input.skill`, 그리고 `UserPromptExpansion`(`/x` 입력).
  - matcher 에 Grep 과 Glob 이 꼭 있어야 한다. 사용자가 지시하면 Grep 으로 우회했다.
  - description 에 "먼저 부르라" 고 적으면 deny 전에 모델이 스스로 부른다.
- compact
  - 순서는 PreCompact, SessionStart(source=compact), PostCompact 다. 표시 상태는 남으므로 SessionStart(compact) 에서 초기화해야 한다.
  - 호출된 스킬 본문은 스킬마다 5k, 합계 25k 까지 재주입되고 오래된 것부터 빠진다. 실험에서는 `/` 로 호출한 본문이 재주입되지 않았다.
- 메인 세션에서 스킬 본문을 늘 싣는 기능은 없다. 방법은 SessionStart additionalContext 뿐이고, 비용은 CLAUDE.md 와 같다.
