# Q23. 패널을 저장소 파일로 바꾼 것을 합칠까? (도구 설명 문구 승인)

## 맥락

**구현 끝(시험 56개 통과, 진짜 저장소 사본으로 옮기기 시험함).** 합치면 이 세션이 다시 로드하면서:
- 지금까지 결정(D1~D22)을 같은 번호의 Q 파일로 쓴다. 답한 것은 `.claude/archive/plan/decisions/`, 열린 것(D22)과 미룬 것(D19)은 `.claude/plan/decisions/`.
- 계획은 `.claude/plan/now.md`.
- 패널 저장소는 화면 상태만 남는다(기록 탭 117건 그대로). 저장소 파일은 미리 백업해 둠.
- 패널은 커밋하지 않는다. 다음 커밋에 같이 들어간다.

**늘 실리는 도구 설명에 더해지는 문장(+217자):**
```
Decisions and the plan are saved as repo files under .claude/plan/ (answered ones move to .claude/archive/plan/decisions/) and go into the next commit; cite a decision as Q3 (older commits say D3).
```
나머지는 예시의 D3 가 Q3 으로 바뀐 것뿐.

**함께 정할 작은 것: 파일 이름**
- 지금: `Q17-plan-md-를-어떻게-바꿀까.md` 처럼 질문의 한국어가 이름에 들어간다. GitHub 에서 읽기 좋지만 터미널 `git status` 에서는 `\354\226...` 처럼 깨져 보인다(설정 `core.quotePath=false` 면 정상).
- 대안: 영어·숫자만 남겨 대부분 `Q17.md`.

**남은 한계:** 두 브랜치에서 같은 번호(Q23)를 동시에 만들면 잡아 주지 않는다(한 사람이 쓸 때는 드묾).
