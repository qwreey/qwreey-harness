# Q37. coderag CLAUDE.md 를 하네스처럼 가리킴 위주로 줄일까?

## 맥락

coderag `CLAUDE.md`
- 72줄, 약 4.4k 토큰이 coderag 세션마다 실림(qwreey-harness 는 약 1.1k).
- 낡은 값이 있음: 시험 수 312(지금 497), "현재 상태" 절의 기능 서술.
- 절: 한 줄 요약, 아키텍처, 워크스페이스 지도(23줄), 불변식 6개, 현재 상태(13줄), 미해결, 작업 규칙.

하네스 규약(`agent-docs`)
- 지워도 모델 행동이 안 바뀌는 문장은 빼고, 현재 사실·지시·가리킴만 둔다.
- 빼는 글은 지우지 않고 옮긴다.

실사용 주간 전에 정하면, 그 주의 측정에 줄어든 크기가 반영됨.

## 선택지

- a) 가리킴 위주로 줄이기(영어)
  불변식·작업 규칙·명령·가리킴만 남김(약 25줄, 1.2k 토큰 목표). 지도와 현재 상태는 `.claude/base/overview.md`·README 로 옮김. 하네스 CLAUDE.md 와 같은 모양
- b) 가리킴 위주로 줄이기(한국어 유지)
  같은 다이어트, 말만 그대로. 한국어는 같은 내용에 토큰이 약 1.4배
- c) 낡은 값만 고치기
  시험 수 등만 고침. 모양은 그대로

**권장 a) 가리킴 위주로 줄이기(영어)**
매 세션 3k 토큰 정도를 아끼고, 하네스와 같은 규약으로 맞춤. 옮긴 글은 base 문서에 남아 필요할 때 찾을 수 있음
