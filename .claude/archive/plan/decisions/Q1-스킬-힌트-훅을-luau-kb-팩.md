# Q1. 스킬 힌트 훅을 luau-kb 팩 스킬부터 넣을까?

## 맥락

**무엇:** 사용자 요청을 정규식으로 보고, 맞으면 "이 요청은 X 스킬에 맞다, 먼저 불러라" 한 줄을 넣는 UserPromptSubmit 훅(audit 58 외부 사례, audit 60 우리 실측).

**우리 실측(audit 60, sonnet):** 훅 없이도 27/32 로드(우리 description 이 이미 잘 맞음), 켜면 32/32. 첫 동작으로 로드 12/27 -> 30/32. 근접 오답 오발 0/7, 일부러 틀린 힌트 0/4 따름.

**이득이 난 곳:** roblox-net("데미지 값 그대로 써도 돼?" 를 끔은 스킬 없이 답함), advisor("PLAN.md 방향 다시 봐줘").

**구조:** 라우터 코드는 `lib/` 정본 사본, 경로는 플러그인·팩마다 `skill-hints.json`, 팩 스킬 힌트는 coderag 가 켜진 팩에서 낸다(coderag 수정 필요). 붙여 넣은 훅 출력 지우기, "뭐야/어떻게" 거르기, 모델 없는 오프라인 경로 시험 포함.

## 선택지

- a) luau-kb 팩부터 작게
  이득이 난 net·perf 가 팩 스킬; 오발 0
- b) recall·agent-records 도 함께
  이미 8/8 이라 보험 수준
- c) 보류
  이득이 작고 coderag 수정이 필요

**권장 a) luau-kb 팩부터 작게**
이득이 실제로 난 곳이 팩 스킬이고 오발이 없었다. advisor 는 모델이 스스로 부르는 스킬이라 넣지 않는다.

## 답

실질적으로 스킬은 사용자가 지시하지 않더라도 실려야하고 … 이것에 약간 기대어 효과를 보겠다는건 의미가 없지 않나 싶어서. 실질적으로 스킬이 안 불리거나 하는것이면 invoke 가 안 되는 문제를 찾아야하는데 대충 땜빵하는거 아닐까 … 근본적으로 도움이 안된다는거. 에이전트의 상황은 다양한데, 매핑이 하나도 안 될것같음
