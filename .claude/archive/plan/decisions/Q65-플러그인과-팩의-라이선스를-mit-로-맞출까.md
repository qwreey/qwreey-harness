# Q65. 플러그인과 팩의 라이선스를 MIT 로 맞출까?

## 맥락

HUMAN_TODO 에서 옮겨 온 질문이에요.

- 플러그인 `plugin.json` 은 이미 모두 `MIT` 로 적혀 있어요
- luau-kb 팩과 coderag 에는 LICENSE 파일이 없어요(`claude plugin validate` 가 알림)
- 정하면 `qwreey-license:license` 스킬로 정본 글을 받아 넣어요

## 선택지

- a) 전부 MIT
  이미 적힌 값과 같고, LICENSE 파일만 더하면 된다
- b) 다른 라이선스
  코멘트로 알려 주면 그것으로
- c) 공개할 때 정한다
  지금은 private 원격뿐이다

**권장 a) 전부 MIT**
적힌 값과 파일이 어긋난 상태만 맞추면 된다
