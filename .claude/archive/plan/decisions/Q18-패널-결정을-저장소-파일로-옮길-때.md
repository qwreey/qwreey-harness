# Q18. 패널 결정을 저장소 파일로 옮길 때 번호와 옛 결정은?

## 맥락

**D17 a 의 앞부분(PLAN.md 나누기)은 에이전트가 진행 중.** 뒷부분 설계안은 이렇다. 정해진 기본값이고, 아래 두 가지만 묻는다.

**설계안**
- 열린 결정: 하나에 파일 하나, `.claude/plan/decisions/<번호>-<짧은 이름>.md`. 기록 규약 그대로(frontmatter, `status: active`). 본문은 질문, 맥락, 선택지와 추천, 코멘트 기록.
- 답하면: 파일에 답을 적고 status 를 닫은 뒤 `.claude/archive/plan/decisions/` 로 옮긴다. 오래갈 규약이면 `base/decisions` 로 따로 올린다.
- 계획 단계: `.claude/plan/now.md` 한 파일을 패널이 덮어쓴다(쌓이지 않음, 지난 것은 git 이 가짐).
- 기록 탭, 읽음 표시, 보내기 대기함은 지금처럼 git 밖 저장소에. 패널은 커밋하지 않고, 에이전트가 다음 커밋에 같이 넣는다.
- coderag 검색, lint, 낡음 검사가 그대로 이 파일들에 걸린다. 동료는 패널로 쓰고 저장소 웹에서 읽는다.

**묻는 것 1: 패널 결정 번호.** 지금 `D13` 이 `base/decisions/D-13` 과 겹친다.
- Q17 꼴(Question): 추천
- 다른 글자를 원하면 코멘트로

**묻는 것 2: 지금까지의 D1~D17.** 커밋 메시지가 "D12 a" 처럼 인용한다.
- 같은 번호로 파일을 만들어 archive 에 넣는다(D12 → Q12, 질문·맥락·선택지·답·코멘트 그대로). 저장소 README 에 "2026-11-17 이전 커밋의 D<n> 은 Q<n>" 한 줄. 추천
- 옮기지 않고 새 번호부터

## 선택지

- a) Q 번호, 옛 결정도 옮김
  커밋의 D<n> 이 저장소 안에서 풀림
- b) Q 번호, 새것부터
- c) 다른 글자
  코멘트로

**권장 a) Q 번호, 옛 결정도 옮김**
이미 커밋 11개가 D 번호를 인용하는데 지금은 어디서도 그 뜻을 못 찾는다. 옮기면 그 커밋들이 저장소 안에서 풀린다.
