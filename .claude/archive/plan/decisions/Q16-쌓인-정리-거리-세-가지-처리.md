# Q16. 쌓인 정리 거리 세 가지 처리

## 맥락

셋 다 급하지 않고 사용자만 정할 수 있는 것.

1. **세션 기록 6건 가져오기:** 자동 요약된 세션 기록 6건(가장 오래된 것 11월 12일)이 저장소 밖에 쌓여 있다. `session-log import` 로 `.claude/sessions/` 에 그대로 넣거나(정리 없이, 스냅숏 머리 줄만), `dismiss` 로 버린다. 넣으면 나중에 recall 로 찾을 수 있다.
2. **readable-code 초안 닫기:** `.claude/research/drafts/readable-code.md` 는 구현이 main 에 들어갔다(rule, 알림, 스위치). `landed in plugins/qwreey-conventions/rules/readable-code.md` 로 닫고 archive 로 옮겨도 되는지.
3. **읽기 좋은 코드 규칙 켜기:** 자기 `~/.claude/harness.env` 에 `HARNESS_READABLE_CODE=on` 한 줄(직접). 켜면 코드 파일을 열 때 rule 이 실리고 편집 뒤 layout 알림이 온다.

코멘트로 각각 답해도 된다(예: "1 가져오기, 2 닫기, 3 나중").

## 선택지

- a) 1 가져오기, 2 닫기
  3 은 직접 할 때
- b) 1 버리기, 2 닫기
- c) 나중에

**권장 a) 1 가져오기, 2 닫기**
기록은 recall 로 찾을 수 있게 두는 편이 낫고, 초안은 내용이 이미 rule 로 옮겨져 현재 근거로 읽힐 필요가 없다.
