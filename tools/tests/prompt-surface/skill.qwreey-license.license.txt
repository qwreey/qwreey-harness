- qwreey-license:license: Writes and checks license files from canonical text, never from memory. Helps the user choose a license, fetches the GitHub or SPDX text with year and holder filled, compares an existing LICENSE and manifest license fields with it, and appends third-party notices. Use when choosing a license, writing or changing LICENSE, NOTICE or THIRD_PARTY_NOTICES, or bringing in code, docs or assets from another project. 라이선스 파일 만들기, 라이선스 정하기, 오픈소스 고지, 서드파티 고지.
