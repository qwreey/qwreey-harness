# 3라운드: conventions 초안(c64b78e) 검토 — P·Q 독립 검토 종합 (중재자: 메인)

## 양쪽이 독립적으로 같은 결론을 낸 것 (반영)
1. **알림에 걸린 글자와 대체를 적는다.** 예: `L12 L15 non-keyboard symbol: — · (use - , ,)`. invisible 은 코드포인트로 적는다(`U+00A0`). history marker 를 범주 순서 맨 앞에 둔다. 모델이 볼 수 없는 문자를 "다시 타이핑하라" 는 지시는 실행할 수 없다. (P3, Q1)
2. **이스케이프 우회가 실제로 일어났다.** 훅 소스의 주석과 docstring 16곳에 `·` 가 `·` 로 들어가 있다. 이것을 막는다.
   - 스킬에 대응표를 둔다: `·`→`, ` 또는 `/`, `—`→` - ` 또는 `:`, `①`→`1)`, `§`→생략.
   - 주석 문장에 `\uXXXX` 같은 이스케이프를 쓰지 않는다는 지시를 넣는다.
   - 훅이 주석 안의 `\uXXXX` 를 잡게 한다.
   - 16곳을 고친다. (P1, Q2)
3. **스킬의 "(U+2190 and up)" 를 지운다.** 경계가 틀렸다. 한글(U+AC00)도 그 위에 있다. (P7, Q4)
4. **적용 순서.** 0005 를 실제 마이그레이션 폴더로 올리는 것, MANIFEST 변경, rules 갱신을 같은 apply 에 묶는다. HOOK-MESSAGES 도 갱신한다. 옛 훅 파일 rm 제안 보류는 8f44388 에서 처리했다. (P5, Q5, 사이드 에이전트)
5. **이름이 quad 의 `.claude/conventions.md` 와 겹친다.** 이름 변경은 사용자에게 제안한다. (P8, Q7)
6. **원장 id 정규식 오탐 후보.** `F64`, `I32`, `X86`, `C99`. Rust/TS 저장소(coderag 등)로 재생해 확인한다. (P9, Q8)

## 한쪽만 낸 것 (반영)
- P2: dedup 을 파일 단위에서 (파일, 범주) 단위로 바꾼다. 흔한 기호 알림이 같은 파일의 이력 표지 알림을 가리지 않게 한다.
- P4: rules/agent-docs.md 와 스킬이 references 에서 모순된다. 규칙에 "references may keep dates, ids and old-pattern notes" 를 더한다.
- P6: 원장 id 의 "함께 배포되는 .md" 조건은 훅이 문법(줄에 .md 가 있는가)만 본다고 스킬에 적는다. 배포 여부는 모델이 판단한다.
- Q3: 늘 로드되는 rules/comments.md 에 이유와 흔한 실수 목록(줄표, 가운뎃점, 줄임표, 화살표, §, 곡선 따옴표, 이모지)을 넣는다. 쓰는 순간에 막는 것은 rules 다.
- Q6: "say why in one clause to the user" 를 "mention it once in your final report" 로 바꾼다(사용자 쪽 잡음).
- Q7: 설정 파일 이름을 바꾸고 comments.json 도 계속 읽는다(이름 확정 뒤).
- Q9: 훅은 모든 문자 체계의 글자를 통과시킨다는 점을 문서에 적는다.

## 소음 수치에 대한 판단
- 양쪽 모두 과도기로는 받아들일 수 있다고 본다. 바꿀 것은 빈도가 아니라 정확도다. 알림이 틀렸거나 고칠 수 없을 때 모델이 흘려 읽는다(추론).
- Q 는 파일 조건부 안을 철회했다. 사용자 기준("사람이 쓴 글로 읽히는가")에서는 기존 — 를 면제할 근거가 없다.
- 확인 방법: 적용 뒤 다음 50커밋을 재생해 symbol 알림 커밋 비율(지금 34/50)이 줄어드는지 본다.

## 사용자 결정
- 플러그인 이름(표준처럼 들리지 않는 것).
- 한국어 주석의 가운뎃점 `·`: 국어 문장 부호 규정에 있고 IME 로 칠 수 있다(Q). 재생 알림 338건이 여기에 달려 있다. 다만 사용자의 메시지들에서는 `·` 대신 "또는", "/", "->" 를 쓴다(메인 확인. dossier 의 "시한성·시각 지정성" 은 메인이 옮겨 적은 것이고, 원문은 "시한성 또는 시각지정성").
