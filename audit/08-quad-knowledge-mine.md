## 우선 이전 추천 Top 15

순서 기준: 실측 근거가 있고, 다른 프로젝트에 바로 적용되며, luau-kb 에 영역 자체가 없는 것.

1. **Q-018 + Q-019 + Q-014 — Deferred 시그널과 Destroy 의 의미론**: 배달은 다음 재개점, Destroy 절단은 큐 1회 배달, 명시 Disconnect 는 드롭, `Connected` 전환만 동기. roblox-luau/signals 의 중심. (Studio 실측 3건)
2. **Q-001 (+Q-002, Q-123) — Luau 에는 ephemeron 이 없다**: weak 표 누수의 정확한 조건과, 이를 잘못 판정하게 만드는 프로브 함정. 가장 자주 되풀이된 함정. luau-perf/gc-weak.
3. **Q-031 + Q-032 + Q-034 — TweenService 엔진 사실 묶음**: 끝난 트윈 Cancel 재발화, Cancel 통지 역전, 파괴 뒤에도 끝까지·무한 트윈 영구, 던지는 건 Create 뿐, 핸들을 잃으면 취소 불가. audit 재현 스크립트까지 있음.
4. **Q-023 — 같은 값 대입은 Changed 0회**: 양방향 바인딩·mock 충실도의 핵심 차이.
5. **Q-088 — `-O2` 인라인이 `debug.info` 프레임을 지운다**: 에러 blame·스택 워커 설계 전반에 적용, 4개 플래그 조합 실측.
6. **Q-012 + Q-013 — Instance userdata 신원과 gcconn 관용구**: Instance 를 weak 키로 쓰는 모든 라이브러리에 해당.
7. **Q-101 + Q-102 + Q-103 — require-by-string 함정 셋**: `init.luau` 와 `@self`, CLI 가 symlink 를 안 따라감, 못 푼 require 를 analyze 가 any 로 떨궈 "거짓 클린". luau-verify 에 바로 붙는다.
8. **Q-095 + Q-096 + Q-098 — 에러 처리 기본기**: `error` 레벨 접두, `err: any`, 핸들러 안 `debug.traceback(nil, 2)`, C 프레임·`task.spawn` 루트에서 접두 소실.
9. **Q-071 — 순회 중 키 추가는 비결정적 누락**: 크래시 없이 콜백 하나가 통째로 빠짐. 이벤트·구독자 구현 전부에 해당.
10. **Q-087 + Q-089 — 할당·검사 비용 실측치**: 인자 전달 방식별 ns 표와 `type(v)=="table"` 선검사 효과. luau-perf 의 첫 실측 표로 적합.
11. **Q-042 — `QueryDescendants` 셀렉터 문법**: 공식 문서에 없는 문법을 전수 프로브로 복원. 단독 가치가 큼(버전 기록 필수).
12. **Q-066 + Q-064 — 코루틴·task 에러 동작**: `resume` 이 에러를 삼킴, dead 스레드 `task.cancel` 은 no-op.
13. **Q-120 + Q-030 — 엔진과 mock 이 갈리는 점 목록, CLI Deferred 심**: luau-testing 의 핵심 자산(mock 사용법이 아니라 차이 목록).
14. **Q-051 + Q-055 — GUI 자동 크기·레이아웃 엔진 규칙**: 킷 없이 재현한 규칙 넷. UI 를 만드는 모든 프로젝트에 해당.
15. **Q-131 + Q-133 + Q-134 — 하네스 운영 실측**: 백그라운드 에이전트 완료 판정, OOM 안전 예산, 병렬 감사 비용과 수렴 방식. harness 스킬의 근거 세트.
