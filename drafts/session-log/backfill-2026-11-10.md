# 세션 기록 소급 생성 (2026-11-10)

## 방법
- 도구: `plugins/session-log` 의 `session-log backfill --plan`. 훅과 같은 `flush` 경로를 쓴다. 그래서 기록 이름 규칙과 상태 파일(바이트 오프셋)이 같다.

- 실행: 세 묶음을 병렬로 돌렸다(동시 3). 묶음마다 $1.3 상한을 두어 합계 상한 $3.9 로 사용자 상한 $4 안이다. `choom -n 1000` 으로 감쌌다.

  - 세션 기록이 날짜별로 있는 곳(quad, table-sim)은 빈 기간만 시간 창으로 요약했다.
- 제외: 이 메인 세션 c9a9e895(claude-doctor), `/tmp/*`·`stl-luau-doctor` 실측 세션(사람 발언 0), 서브에이전트 트랜스크립트.
